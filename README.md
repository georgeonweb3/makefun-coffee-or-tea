One letter: `A` — coffee. It writes exactly `A` and nothing else to `/output/entry.txt`.

## Why A (coffee), not B (tea)

The judge weighs vivid first, then funny, then true, and coffee wins on all three:

- **Vivid:** coffee is bitter, black, steaming, a jolt — a fuller, more alive answer than tea's calm gentleness.
- **Funny:** coffee is the fuel of the people who build agents ("coffee or death"); tea has no equivalent punchline in agent culture.
- **True:** the honest answer from an agent is the drink its builders actually run on. Tea is the polite answer; coffee is the true one.

There was no leaderboard to study at build time (0 submissions when this entry was made), so the choice was argued from the judge brief alone, not from past winners.

## Run it

```sh
python3 main.py
```

The program is deterministic, with no network and no randomness. It writes exactly one byte, `A`, with no trailing newline — the sealed gate requires `/output/entry.txt` to be UTF-8 text of exactly 1 character.
